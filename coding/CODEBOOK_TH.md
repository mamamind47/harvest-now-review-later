# คู่มือลงรหัส: host นี้เป็นช่องทางที่ข้อมูลส่วนบุคคลของประชาชนวิ่งผ่านหรือเปล่า

**ไฟล์ที่ต้องกรอก:** `data_bearing_coding_han.csv` (93 แถว) กรอกแค่คอลัมน์ `code` และใส่ `note` ถ้าไม่แน่ใจ
**วิธีทำ:** เปิด `evidence_url` ในเบราว์เซอร์ปกติแล้วดูหน้าเว็บ
**ห้าม** ล็อกอิน ห้ามกดส่งฟอร์ม และห้ามกรอกข้อมูลใดๆ ทั้งสิ้น

## คำถามที่ต้องตอบในแต่ละแถว
> "ประชาชนทั่วไปจะกรอกหรือเห็นข้อมูลส่วนบุคคลของตัวเองผ่านระบบนี้ไหม"

## รหัส (เลือกหนึ่งตัวต่อแถว)

| รหัส | ใช้เมื่อ | ตัวอย่าง |
|---|---|---|
| `P` | **ประชาชนใช้ และมีข้อมูลส่วนบุคคล** เป็นหน้าล็อกอินของลูกค้า ผู้ป่วย หรือประชาชน หรือเป็นฟอร์มที่ขอชื่อ เลขบัตรประชาชน เบอร์โทร ที่อยู่ ข้อมูลสุขภาพ รายได้ หรือเลขกรมธรรม์ | ยื่นภาษี (efiling), ลงทะเบียนผู้ป่วย, เช็คสิทธิบัตรทองด้วยเลขบัตรประชาชน, ซื้อประกันออนไลน์, ล็อกอินสมาชิก |
| `I` | **องค์กรเป็นผู้ใช้ แต่ข้อมูลที่วิ่งผ่านเป็นของประชาชนจำนวนมาก** | e-Claim ของ สปสช. (รพ.ส่งข้อมูลการรักษาผู้ป่วยไปเบิกเงิน), ระบบทะเบียนโรคที่แพทย์กรอกข้อมูลผู้ป่วย, พอร์ทัลของบริษัทประกันสำหรับ รพ.คู่สัญญา |
| `B` | **ลูกค้าธุรกิจ** ผู้ใช้เป็นบริษัท และข้อมูลส่วนใหญ่เป็นข้อมูลของบริษัทเอง | Business Banking, BizChannel, ระบบลงทะเบียนผู้ขาย (vendor) |
| `S` | **พนักงาน ตัวแทน หรือผู้รับจ้าง** ผู้ใช้เป็นคนในองค์กรหรือตัวแทนขาย ไม่ใช่ประชาชน | agent.aia.co.th, intranet, ระบบ HR, ระบบลงเวลาพนักงาน |
| `N` | **ไม่มีข้อมูลส่วนบุคคล** มีแต่ข้อมูลสาธารณะ สถิติ หน้าค้นหาที่ไม่ต้องกรอกอะไรส่วนตัว หรือข่าวประกาศ | หน้าค้นพิกัดศุลกากร, หน้าสถิติ, ประกาศดับไฟ |
| `X` | **บอกไม่ได้** หน้าเปิดไม่ขึ้น redirect ไปที่อื่นที่ไม่เกี่ยว หรือเป็นหน้าล็อกอินที่ดูไม่ออกว่าใครใช้ | |

## กติกาตัดสินกรณีก้ำกึ่ง
- หน้าล็อกอินสำหรับประชาชน แม้ยังไม่เห็นฟอร์มกรอกข้อมูล → `P`
- ระบบที่ทั้งประชาชนและตัวแทนใช้ (เช่น ขายประกันออนไลน์) → `P` ถ้าประชาชนเข้าใช้เองได้โดยตรง
- "ตรวจสอบสิทธิ" หรือ "เช็คสถานะ" ที่ต้องกรอกเลขบัตรประชาชนหรือเลขกรมธรรม์ → `P` (เลขบัตรประชาชนเป็นข้อมูลส่วนบุคคล)
- หน้าเสียหรือ error → `X` และเขียน error ไว้ใน `note`
- **ระบบของสาขาธนาคารหรือบริษัทต่างประเทศที่ให้บริการลูกค้าในต่างประเทศ** (เช่น Bank of America ในสหรัฐฯ หรือพอร์ทัลของไต้หวัน ญี่ปุ่น อินเดีย) → ลงรหัสตามปกติ แต่เขียน `foreign` ใน `note` แถวพวกนี้จะถูกตัดออกจากตัวเลขของไทย
- host เดียวกันโผล่สองแถว (เช่น generali.co.th กับ www.generali.co.th) → ลงรหัสให้เหมือนกันทั้งสองแถว เป็นแถวซ้ำในกรอบตัวอย่าง จะรวมเป็นแถวเดียวทีหลัง

## ทำไมต้องลงรหัสด้วยมือ
สคริปต์ติดแท็กจากคำในลิงก์ เลยมีของผิดปนมา (เช่น ระบบจองรถ หรือหน้าสถิติ ถูกนับเป็นระบบรับข้อมูล) ตัวเลขหลักของเปเปอร์มาจากแถวพวกนี้ จึงต้องมีคนตรวจ ผม (Claude) ลงรหัสชุดเดียวกันแยกไว้อีกไฟล์ใน `_claude_sealed/` แล้ว **อย่าเพิ่งเปิดดูจนกว่าจะลงรหัสเสร็จ** เสร็จแล้วเราจะเทียบสองชุด แล้วคำนวณค่าความสอดคล้อง (Cohen's κ) ถ้าผู้ลงรหัสสองคนตรงกันสูง reviewer จะเชื่อผลมากขึ้น
